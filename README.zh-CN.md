# Vox Dictation

[English](README.md) | 中文

一个 macOS 听写工具，不只是把语音转成文字——它会改稿。点 **ASR 录入** 说话，这段语音先成为一条**指令**：点 **AI整理** 把它并进你正在写的正文，点 **AI修改** 按它的要求改写已有内容。文字留在应用自己的输出框里，复制出去就能用。

![screenshot](docs/screenshot.png)

## 使用

- **ASR 录入** — 点一下开始，再点一下停止。每说一次就是一条带编号的指令。
- **AI整理** — 把新增内容整理成和现有正文一致的格式，接在后面、编号顺延，已有文字保持原样。
- **AI修改** — 把这段口述当作修改要求，应用到现有正文上。
- **复制输出** / **清空全部** — 把结果放进剪贴板，或者推倒重来。执行过的指令沉到历史记录，不会再被发出去。

界面支持中英双语，默认跟随系统，可在 **设置 → 应用设置** 里手动切换。

## 配置

全部在右下角 **设置** 里，分 **大模型 / 语音识别（ASR）/ 应用设置** 三栏。

大模型：选厂商（DeepSeek、OpenAI、Moonshot、智谱 GLM、硅基流动、Ollama、LM Studio、自定义），接口地址和模型名按厂商预填、可改，填入自己的 API Key；本地运行时不需要 Key。Key 存在系统钥匙串。每栏都有 **测试连接** 按钮，只验连通性，不会上传音频。

语音识别：要么指向本地的 sherpa-onnx（流式 `:6006`、定稿 `:6007`），要么用任意 OpenAI 兼容转写接口——内置 OpenAI、Groq、硅基流动、Deepgram、阿里云百炼 Qwen-ASR、百度短语音；其他能说 OpenAI 转写协议的用「自定义」接。

## 编译

需要 macOS 14 或更新，以及 Xcode 16 / Swift 6 工具链。

```bash
./build.sh       # release 构建，组装并 ad-hoc 签名 Vox.app
./build.sh run   # 同上，构建完直接打开
```

产物是项目目录下的 `Vox.app`。应用做了 ad-hoc 签名，麦克风权限要靠这个稳定身份。
